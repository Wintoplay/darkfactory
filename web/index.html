        or

        On a phone, open the link from Pair phone, or enter the code shown there. The code expires in 2 minutes and works once.

        The server binds to 127.0.0.1 by default. For a phone, use Tailscale Serve or an SSH tunnel — never a public bind.

        Pair a phone

        Scan the QR with the phone camera, open the link, or enter the code there. The code expires in 2 minutes and works once.

        The name and access are made here; the phone cannot change them. Workspace access is terminal and OpenCode together, because an OpenCode turn can already run workspace actions. Changing either generates a new code.
